# Mubara Saleem — Personal Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, responsive styling and theme styles
- `script.js` — mobile navigation, theme toggle and current year

## Preview locally
1. Extract the ZIP file.
2. Open the `mubara_portfolio` folder.
3. Double-click `index.html` to open it in your browser.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Before publishing
Update the placeholder GitHub, LinkedIn and email links in `index.html`. Review the education wording and project descriptions to ensure they accurately reflect your current work.
